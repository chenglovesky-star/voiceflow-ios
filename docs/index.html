主引擎 · iOS 26+

Apple SpeechAnalyzer

Apple 原生 API，系统级优化，长音频无压力，完全离线。

  • 零运营成本，不调用 API
  • 长音频（1 小时+）稳定
  • 系统语言自动适配
  • 隐私：音频留在设备
备用引擎 · iOS 17-25

WhisperKit

OpenAI Whisper 模型的原生 Swift 实现，覆盖 iPhone XS (A12) 及以上老设备。

  • 覆盖 ~95% 在用 iPhone
  • Core ML 加速，本地推理
  • 多语言识别能力强
  • 同样无需网络

→ TranscriptionServiceFactory.make() 启动时自动检测系统版本并选择引擎
