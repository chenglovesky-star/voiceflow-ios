# 🎙️ VoiceFlow（占位名）— MVP 头脑简报

> 「录完即得文字稿，无需跨 app」

## 1. 项目概述

**一句话定位**：iOS 录音 App，录完音频自动得到文字稿和 AI 兼容格式（M4A/MP3），跳过传统"录音→转码→上传 AI"4 步工作流。

**核心用户**：
- 律师 / 咨询 / 记者：长会议要文字稿，注重隐私（本地转写）
- 学生：上课录音转笔记
- 内容创作者：采访、播客录制后立即得稿
- AI 重度用户：录完直接送给 ChatGPT/Perplexity/Gemini

**核心场景**：
```
按下录音 → 实时转文字 → 停止 → 自动生成 .txt + .m4a
       → 一键分享到 AI app（直接送文字稿，无 25 MB 限制）
```

**目标市场**：先美区（[[dc-2026-04-27-711]] 用户来自 US Store，付费意愿强）。

---

## 2. 核心价值（为什么这个能成）

| 痛点 | 现有方案 | 我们的方案 |
|------|----------|------------|
| 通用录音 App 输出 WAV 太大，AI 不收 | 用户买二级转码 App（$13）| 默认录 M4A/AAC，直接送 AI |
| 转完文字要跨 app | 录音 → 文件 → 上传 → 等转写 | 录完文字稿已就绪 |
| 云转写隐私顾虑 | Otter / Rev 上传云端 | 纯本地（iOS 26 SpeechAnalyzer）|
| 长会议文件超限 | 手动剪段或压缩 | 默认 0.5 MB/分钟，30 min ≈ 15 MB |
| 订阅疲劳 | 大多数对手收订阅 | **一次性买断 $4.99**（参考 [[dc-2026-04-27-862]] 反杀熟集群信号）|

**本质**：把分散在 4 个 app 的工作流压缩到 1 个屏幕，并用本地 AI 把"格式不兼容"问题彻底消除。

---

## 3. MVP 范围（只做这些）

### 3.1 必须有（P0，第 1 周）
- [ ] 一键录音（默认 M4A AAC 64kbps 单声道，可切多声道/高码率）
- [ ] 实时波形 UI + 录音时长
- [ ] 录完自动跳详情页 + 后台异步转写（SpeechTranscriber）
- [ ] 文字稿展示 + 复制 / 分享 / 导出 TXT
- [ ] 录音列表（按时间倒序）+ 重命名 / 删除

### 3.2 后面再做（P1，第 2 周）
- [ ] 时间戳跳读（点文字跳到对应秒）
- [ ] 文字稿就地编辑
- [ ] 分享菜单导出 M4A / MP3 / SRT / Markdown
- [ ] iCloud 同步（CloudKit，零运维）
- [ ] iOS 25- 用户走 WhisperKit 分支

### 3.3 第 3 周（P2，差异化）
- [ ] **"送给 AI"按钮** → 直接调用 Perplexity/ChatGPT/Gemini 的 share-sheet（已装就走 URL Scheme，未装则复制文字稿）
- [ ] 标签 / 文件夹组织
- [ ] 导入外部录音文件转写（处理别人 app 的 WAV，**这是杀手锏**——直接解 711 用户原始痛点）

### 3.4 绝对不做（本期）
- 云端转写后端
- 账号体系（用 iCloud + Apple ID）
- 订阅
- 团队协作

## 4. 数据流

```
┌─────────────────────────────────────────────────────────┐
│  AVAudioRecorder（M4A AAC 64kbps）                       │
│       ↓ 实时音频流                                       │
│  AVAudioEngine + AVAudioPCMBuffer                       │
│       ↓ 喂给                                             │
│  SpeechAnalyzer + SpeechTranscriber（iOS 26 本地）       │
│       ↓ 流式输出                                         │
│  文字稿（含词级时间戳）→ Core Data                       │
│       ↓ 写入                                             │
│  ./Documents/recordings/{uuid}.m4a + transcripts.db     │
│       ↓ 用户操作                                         │
│  分享 / 导出 / 送 AI                                     │
└─────────────────────────────────────────────────────────┘
```

## 5. 技术栈选择

### 5.1 核心
| 组件 | 选择 | 理由 |
|---|---|---|
| 语言 | Swift 6 | iOS 26+ 推荐 |
| UI | SwiftUI | iOS 26 新 API 友好 |
| 录音 | `AVAudioRecorder` + `AVAudioEngine` | 原生、稳定 |
| 转写（主） | `SpeechAnalyzer` + `SpeechTranscriber` | iOS 26+，本地，免费 |
| 转写（fallback） | `WhisperKit` | iOS 17–25 兼容 |
| 转码 | `AVAssetExportSession` + `AVAudioConverter` | 原生 M4A↔MP3 |
| 存储 | Core Data + FileManager | 文字稿入库，音频文件落盘 |
| 同步 | CloudKit | 零运维 |
| 分发 | TestFlight → App Store（美区先） | — |

### 5.2 不引入的依赖
- ❌ LAME（MP3 编码 license 麻烦，原生 `AVAudioConverter` 直接出 MP3）
- ❌ Whisper API / Gemini API（运营成本 + 隐私顾虑，纯本地是卖点）
- ❌ Firebase / Sentry（先用 Xcode Crash Reports，足够 MVP）

## 6. 屏幕流（5 屏）

```
[录音首页]──长按麦克风按钮──→[录音中（波形+时长）]
   ↑                              │
   │                            停止
   │                              ↓
[设置页]                  [详情页（音频+文字稿）]
   │                              │
   │                          分享按钮
   │                              ↓
   └─────────────────────[导出菜单（M4A/MP3/TXT/送AI）]
```

P0 需要的 5 屏：
1. **录音首页**：列表 + 大录音按钮 + 标签筛选
2. **录音中**：波形 + 时长 + 停止按钮
3. **详情页**：上半音频播放器 + 下半文字稿（可滚）
4. **分享/导出菜单**：M4A / MP3 / TXT / 复制全文 / "送给 AI"
5. **设置页**：默认格式 / 默认采样率 / iCloud 开关 / 关于

## 7. 风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| iOS 26 SpeechAnalyzer 在长音频/低性能设备掉精度 | 🟡 中 | 测试 iPhone 12+，长音频自动分段（10 min/段） |
| 后台录音 background mode 审核 | 🟡 中 | 提交时附说明视频："长会议录制场景" |
| 类似 app 多 | 🟡 中 | 强调"本地+不订阅"差异化文案 |
| Apple 升级"语音备忘录"吃掉市场 | 🟢 低 | 短中期窗口稳定，长期靠"导入外部录音转写" + 创作者工作流 |
| 美区 ASA 投放成本 | 🟡 中 | 单关键词 ≤ $1.5 CPI，先 $300 测试 |
| 评审拒绝（功能太基础） | 🟢 低 | 主打"长录音 + 本地转写 + AI 分享"组合，不是单点 |

## 8. 商业化与定价

**定价（一次性买断，参考反订阅信号集群）**：
- $4.99 一次性（首发促销 $2.99）
- 可选 Pro $9.99/年（不做，除非 P0 数据验证有付费需求）：
  - 多人识别
  - 导出 Markdown 模板
  - 多语言扩展模型

**单位经济（保守估算）**：
- 月下载 1000，付费率 5% → 50 × $4.99 = $250
- Apple 70% → ~$175 净收入
- ASA 测试 $300/月 → 第 1 月 -$125，第 2-3 月 break-even
- LTV 取决于口碑续推

**收入上限拍脑袋**：若做到 ASO 关键词 "voice recorder transcription" / "audio to text" 前 5 名，参考 Just Press Record（$5）量级，年 $50K-$200K 可期。

## 10. 成功标准（MVP）

**T+7 天**：
- [ ] App Store 美区上架成功
- [ ] 下载 ≥ 50（卡片砍掉条件之一）
- [ ] 用户评分 ≥ 4.0

**T+30 天**：
- [ ] IAP 转化率 ≥ 1%（卡片砍掉条件之二）
- [ ] 月下载 ≥ 200
- [ ] 至少 3 条具体反馈来自"我用它转录会议/采访/课程"

- T+7 下载 < 50：暂停 ASA，复盘文案/截图
